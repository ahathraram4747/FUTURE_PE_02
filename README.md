# AI Content Marketing using UGC Ads
## Project Overview
This project is created as part of the Future Interns Prompt Engineering Internship – Task 2.
The project focuses on using AI prompt engineering to create UGC-style marketing content for a skincare product.
### Brand
GlowNest Skincare
### Product
GlowNest Hydrating Face Serum
### Target Audience
Young adults looking for a simple and consistent skincare routine.
## Project Objectives
- Create engaging UGC-style advertisement scripts
- Generate multiple attention-grabbing hooks
- Create problem-solution-CTA based advertisements
- Adapt content for Instagram, Facebook, and YouTube Shorts
- Generate captions and calls-to-action
- Use structured prompts for consistent AI-generated marketing content
## Tools Used
- ChatGPT
- GitHub
- Google Docs / MS Word
## Deliverables
- UGC Ad Hooks
- UGC Ad Scripts
- Platform-specific Ad Versions
- Captions
- Calls-to-Action
- Prompt Logic and Outputs
